# Projeto Nivelamento

## Objetivo
Manter os fundamentos em dia.

## Descrição
Este projeto em C# permite ao usuário inserir uma sequência de números e obter estatísticas sobre os valores inseridos, como soma, média, menor e maior valor. 

## Funcionalidades
- Coleta de números inteiros positivos até que o usuário insira um valor negativo para encerrar a entrada.
- Cálculo e exibição de estatísticas sobre os números inseridos.

## Tecnologias Utilizadas
- C#
- .NET
